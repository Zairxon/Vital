# Vital — хранилище семейных документов (Android APK)

**Дата:** 2026-09-22
**Статус:** дизайн утверждён, готов к плану реализации

## Задача

Приложение на телефон, где лежат документы всех членов семьи: паспорта,
свидетельства о рождении, дипломы, объективки в Word. Документ можно найти,
открыть, увеличить фото и отправить нужному человеку.

## Решения, принятые на этапе дизайна

| Вопрос | Решение |
|---|---|
| Где хранятся файлы | Только в телефоне, в приватной папке приложения. Без облака |
| Защита | PIN из 4 цифр + отпечаток/Face Unlock, авто-блокировка |
| Структура | Человек → его документы. Плюс общий поиск и фильтр по типу |
| Стек | React 19 + Vite + Capacitor 7 → APK |
| Добавление | Камера, галерея, файлы с телефона (PDF, Word) |
| Word / PDF | Открываются во внешнем приложении телефона |
| Название | Vital |

## Архитектура

Веб-приложение (React + Vite), упакованное в APK через Capacitor. Никакого
сервера и сетевых запросов — приложение работает полностью офлайн.

```
vital/
├── src/
│   ├── pages/          Lock, People, Person, Viewer, Settings
│   ├── components/     карточки, модалки, зум-просмотрщик, UI-примитивы
│   ├── lib/
│   │   ├── storage.js  метаданные: чтение/запись JSON
│   │   ├── files.js    файлы: сохранить, прочитать, удалить, поделиться
│   │   ├── auth.js     PIN (хеш), биометрия, авто-блокировка
│   │   ├── backup.js   экспорт/импорт ZIP
│   │   └── search.js   поиск и сортировка
│   └── styles/         тема Botanical Earth, Inter
├── android/            генерируется Capacitor
└── docs/
```

### Слои и границы

- **`files.js`** — единственное место, которое знает про Capacitor Filesystem.
  Наружу отдаёт: `saveFile(blob, ext) → fileId`, `getFileUrl(fileId)`,
  `deleteFile(fileId)`, `shareFiles(fileIds)`, `openExternally(fileId)`.
  В браузере (dev-режим) те же функции работают через IndexedDB — поэтому
  интерфейс можно разрабатывать и проверять без телефона.
- **`storage.js`** — только метаданные, ничего не знает о том, где лежат байты
  файлов. Хранит один JSON-документ, пишет его атомарно после каждого изменения.
- **`auth.js`** — PIN и биометрия. Остальное приложение видит только
  `isUnlocked`, `unlock()`, `lock()`.
- Экраны не обращаются к Capacitor напрямую — только через `lib/`.

## Хранение данных

**Файлы:** приватная директория приложения (`Directory.Data`), путь
`vital/files/<fileId>.<ext>`. Для картинок дополнительно генерируется миниатюра
`vital/thumbs/<fileId>.jpg` (ширина 400 px) — чтобы списки открывались мгновенно
и не грузили в память полные фото.

**Метаданные:** `vital/db.json`.

```js
{
  version: 1,
  people: [
    { id, name, relation, avatarFileId, order, createdAt }
  ],
  documents: [
    {
      id, personId,
      type,            // 'passport' | 'birth' | 'marriage' | 'diploma'
                       // | 'objectivka' | 'inn' | 'military' | 'other' | свой
      title,           // 'Паспорт AA1234567'
      note,            // свободная заметка
      expiryDate,      // необязательно
      pinned,          // закреплён вверху
      order,
      createdAt,
      pages: [
        { fileId, kind: 'image' | 'pdf' | 'doc', mime, size, name }
      ]
    }
  ],
  customTypes: [ { id, label } ]
}
```

Один документ = одна карточка с несколькими страницами: паспорт хранится как
разворот + прописка + виза внутри одной записи.

## Экраны

### 1. Вход (Lock)

Клавиатура PIN из 4 цифр. Если в телефоне настроен отпечаток — предлагается
сразу при открытии. Блокировка срабатывает при запуске и когда приложение было
свёрнуто дольше минуты. Три неверных PIN подряд — пауза 30 секунд.
Включён `FLAG_SECURE`: содержимое не попадает в скриншоты и в превью списка
задач Android. Отключается в настройках.

### 2. Главная (People)

Список людей: аватар, имя, кем приходится, количество документов. Порядок
меняется перетаскиванием. Сверху — поиск, который ищет **по всем документам
сразу**: по имени человека, названию и типу документа. Кнопка «+ человек».

### 3. Человек (Person)

Документы этого человека, сгруппированные по типу; закреплённые (звёздочка) —
вверху. Карточка показывает миниатюру, название и число страниц. Кнопка
«+ документ» открывает выбор: снять камерой / выбрать из галереи / выбрать файл.
При добавлении спрашивается тип и название; тип можно создать свой.

### 4. Просмотр (Viewer)

- **Фото:** на весь экран, щипок и двойной тап — зум, свайп — между страницами,
  счётчик «2 / 3».
- **PDF и Word:** иконка формата, имя файла, размер, кнопка «Открыть» —
  передаёт файл во внешнее приложение телефона.
- Снизу: **Отправить** (системное меню «Поделиться» — Telegram, WhatsApp,
  почта; можно отправить одну страницу или весь документ), Изменить
  (название, тип, заметка, порядок страниц, добавить страницу), Удалить.

### 5. Настройки

Смена PIN, отпечаток вкл/выкл, запрет скриншотов вкл/выкл, **«Экспорт всего в
ZIP»** (все файлы + `db.json`, сохраняется через «Поделиться») и **«Импорт из
ZIP»** для восстановления на новом телефоне. Внизу — сколько места занимают
документы.

## Обработка ошибок

- Отказ в доступе к камере, галерее или файлам — понятное объяснение и кнопка
  «Открыть настройки приложения», а не пустой экран.
- Нет места на диске при сохранении — файл не записывается, метаданные не
  меняются, показывается сообщение.
- Файл пропал (стёрли извне) — карточка помечается «файл не найден», остальное
  приложение работает; можно заменить страницу или удалить запись.
- `db.json` не читается или битый — приложение поднимается на последней
  сохранённой копии (`db.json.bak`, пишется перед каждой записью), пользователь
  видит предупреждение.
- Удаление документа и человека — с подтверждением, где явно написано, сколько
  файлов будет стёрто.

## Проверка

1. Дев-сервер в браузере: все экраны и сценарии работают на IndexedDB-заглушке
   файлов — проверяю сам.
2. Юнит-тесты на чистую логику без телефона: `storage.js` (добавление,
   удаление, миграция версии), `search.js` (поиск, сортировка, закрепление),
   `auth.js` (хеш PIN, счётчик неверных попыток, таймер блокировки).
3. Сборка APK и установка на телефон — камера, отпечаток, отправка и открытие
   Word проверяются вживую пользователем.

## Этапы

1. **Каркас**: проект, тема, люди, документы, добавление из галереи и камеры,
   просмотр фото с зумом.
2. **Файлы**: PDF и Word, открытие во внешнем приложении, несколько страниц.
3. **Защита**: PIN, отпечаток, авто-блокировка, FLAG_SECURE.
4. **Отправка и бэкап**: «Поделиться», экспорт и импорт ZIP.
5. **APK**: иконка, имя Vital, сборка релизного APK.

## Сознательно не делаем сейчас

Облачную синхронизацию, распознавание текста с документов (OCR), напоминания об
истечении срока действия, совместный доступ для родственников. Всё это
добавляется поверх готовой структуры, если понадобится.
